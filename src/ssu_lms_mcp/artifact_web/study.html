나의 학습 라이브러리

문서는 이 PC의 OneDrive 폴더에 저장됩니다. 로컬 파일 저장 완료는 클라우드 동기화 완료를 뜻하지 않습니다. 동기화 상태는 OneDrive 앱에서 확인하세요.

  • Ctrl / ⌘ + S 문서 저장 · / 제목·속성 검색
  • 본문은 전체 Markdown을 편집하며 읽기 화면에서 수식, 표, 답안 펼치기, 콜아웃을 확인합니다.
  • 저장하지 않은 문서와 미제출 답안은 이 탭의 임시 초안으로 보관됩니다. 파일의 저장본이 기준이며 초안은 OneDrive에 동기화되지 않습니다.
  • 복습 답안과 자기 평가는 직접 입력하고 제출하세요. 다음 학습 실행에서 처리되며 자동 채점하지 않습니다.
  • 자동 생성 스냅샷의 경계는 읽기 화면에서 간결하게 표시됩니다. 전체 원문은 편집 화면에 그대로 남아 있습니다.

로컬 런타임: markdown-it 15.0.2 · DOMPurify 3.4.16 · KaTeX 0.18.9. 네트워크/CDN을 사용하지 않습니다.
